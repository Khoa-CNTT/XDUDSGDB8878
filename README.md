## 🌟 Giới Thiệu

## 🚧 Triển Khai

### Yêu cầu
- Docker
- Docker Compose

### Hướng dẫn triển khai
```bash
# Clone repository
git clone https://github.com/Khoa-CNTT/XDUDSGDB8878.git

# Di chuyển vào thư mục dự án
cd XDUDSGDB8878

# Khởi chạy với Docker Compose
docker-compose up --build
```
