# 🏡 Hệ Thống Quản Lý Bất Động Sản Thông Minh

## 🚀 Phiên Bản: v0.0.1 - Initial Stable Release

      Chào mừng bạn đến với hệ thống quản lý bất động sản thông minh! 
      Dự án này cung cấp giải pháp toàn diện để quản lý, theo dõi và 
      tương tác với bất động sản theo cách hiện đại, kết hợp các 
      công nghệ AI và giao diện người dùng thân thiện.

---

## 🆕 Tính Năng Nổi Bật

🔹 **Dockerized Setup**  
Hệ thống được đóng gói sẵn với Docker, hỗ trợ triển khai nhanh chóng và linh hoạt thông qua `docker-compose`.

🌀 **Spring Boot Backend**  
API backend được xây dựng với Spring Boot, cung cấp các endpoint RESTful cho toàn bộ hệ thống.

⚛️ **ReactJS Frontend**  
Giao diện người dùng được xây dựng bằng ReactJS, mang đến trải nghiệm mượt mà và hiện đại.

🌟 **Tích Hợp Gemini AI**  
Ứng dụng AI của Google Gemini giúp xử lý và phân tích dữ liệu thông minh hơn.

🐍 **Dịch Vụ Flask**  
Dịch vụ Flask API phụ trách các tác vụ nền và xử lý dữ liệu chuyên sâu.

🧠 **Hỗ Trợ DeepSeek AI**  
DeepSeek AI được tích hợp để nâng cao khả năng xử lý ngôn ngữ tự nhiên và tương tác với người dùng.

---

## 🛠️ Cải Tiến & Sửa Lỗi

- Tối ưu giao tiếp giữa Flask và Spring Boot thông qua API Gateway.  
- Cải thiện hiệu suất AI khi sử dụng kết hợp DeepSeek và Gemini.  
- Sửa lỗi kết nối giữa ReactJS và Flask API.  
- Tăng khả năng triển khai linh hoạt với Docker Compose.
